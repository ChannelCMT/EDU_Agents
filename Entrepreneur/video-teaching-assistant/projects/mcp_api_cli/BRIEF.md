# BRIEF：MCP / API / SDK / CLI / Function Calling / Tool Calling / ADK

## Communication job

让第一次接触 Agent 的企业家和大学生，能够把 7 个术语放回同一张分层地图，并知道它们在真实任务中如何协作。

## Review deliverables

1. `SCRIPT.md`：3 分 30 秒中文讲稿审核稿。
2. `script/voiceover-v01.md`：按语义句切分的后续配音源文本。
3. `storyboard/semantic-beat-manifest.yaml`：每个动画节点、时间窗口和 QA 门禁。
4. `hyperframes/index.html`：course-videoLoop 风格的可运行动画草稿，不含配音、不渲染 MP4。
5. `ppt/AgentTechStack_review.pptx`：可编辑 PPT 审核稿，含演讲者备注。

## Frozen visual direction

- 深蓝底：`#06182A`
- 浅蓝高亮：`#8ED6FF`
- 白字：`#F7FBFF`
- 浅灰辅助：`#B8C4D2`
- 黄色结论/关键节点：`#FFD66F`
- 1920×1080；底部 900–1080px 预留字幕安全区。
- 采用“总图 → 局部放大 → 回到总图”的 Course Loop 叙事，不用并列卡片堆满画面。

## Scope boundary

本阶段不生成 Fish Audio 音频、数字人、字幕或 MP4。审核通过后，才进入配音、词级对齐、动画审查和渲染。
