# PPT Harness：背景线与视觉层级

## 背景网格约束

背景网格只承担“科技纹理”作用，不承担信息表达。它必须比正文、图形边框和主分隔线弱至少一个层级。

- 网格线颜色：`#0B2236`。
- 网格线相对背景对比度上限：`0.12`。
- 网格线不得进入任何文字、节点或字幕安全区的视觉焦点。
- 顶部分隔线单独使用 `#1B4058`，宽度 1px，不得使用与网格相同的亮度。
- PPT 必须保留与成片一致的左上、右下蓝色径向光晕；光晕只能作为背景层，不能压过正文。
- 任何一页如果网格线在缩小到手机预览时仍然抢过文字，必须降低透明度，不得通过缩小文字解决。

## 审查动作

1. 逐页以 100% 查看背景线是否先于正文被注意到。
2. 用手机比例或缩略图查看：标题和主要节点必须先被识别。
3. 检查网格与字幕安全区是否产生一条“视觉基线”，避免字幕像贴在网格上。
4. PPT 与 HyperFrames 必须使用同一组网格颜色、透明度和顶部分隔线规则。

## 失败处理

若背景线过重：先调网格颜色/透明度；若仍然过重，再减少网格密度。禁止通过降低标题字号、降低正文对比度或增加阴影来补救。
