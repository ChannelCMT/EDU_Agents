# 第 5 章｜Graph Workflow：把选型落到生产环境

版本：v02  
状态：已批准  
章节学习结果：能用三问完成一次架构选型记录

## 段落 1｜Graph Workflow

Graph Workflow 用图来编排长流程：节点代表步骤，边代表条件；它可以支持分支、并行、回溯和重试，所以最适合流程自动化和生产环境。

## 段落 2｜演进线与三问清单

你可以把七种架构排成一条演进线：单 Agent 做最小验证，ReAct 做多步探索，Plan and Execute 做工程化，多 Agent 做角色协作，Route+Skill 做精准技能系统，Blackboard 管共享状态，Graph Workflow 承载长流程。最后用三问做选择：任务有多复杂？哪里必须可控？失败后能不能重试和回滚？没有最好的架构，只有最合适的架构。

## 动画意图

- 先出现 Graph 节点，再逐一画出条件分支、并行路径、回溯线和重试环。
- 演进线从左到右按语义逐节点点亮，不提前显示三问。
- 结尾把三问放入安全区上方的半透明卡片，留出字幕安全带。
