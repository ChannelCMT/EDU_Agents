# 课程教学与 GitHub 使用

## 教学目标

完成本课程后，学习者应该能够：

1. 把原始视频或长文改成分章课程讲稿；
2. 制作可执行的语气与术语读音计划；
3. 用最终音频建立词级语义时间轴；
4. 设计与口播同步的 PPT 风格动画；
5. 用 Harness 检查布局、字幕、媒体流和封面；
6. 用最小返工 Loop 修复问题并形成发布包。

## 建议课时

| 模块 | 主题 | 动手产物 |
|---|---|---|
| 1 | 素材盘点与转录 | 素材清单、术语表、规范转录 |
| 2 | 五章结构与讲稿改写 | 章节计划、第一章 SCRIPT |
| 3 | 语气规划与 Fish Audio | 15 秒声音样片、tone-plan |
| 4 | 逐词对齐与语义锚点 | word-alignment、anchor plan |
| 5 | PPT 动画与 20 秒试片 | pilot MP4、layout audit |
| 6 | 双门禁与逐章渲染 | QA 报告、章节 MP4 |
| 7 | 字幕、合并和媒体检查 | subtitle manifest、总片 |
| 8 | 封面、发布文案与复盘 | 发布包、Harness 新规则 |

## 真实练习

选择一段 45–90 秒的自有素材，完成一个最小章节：

- 一份版本化讲稿；
- 术语和语气表；
- 一条批准配音；
- 至少 8 个语义锚点；
- 15–20 秒对齐试片；
- 一行字幕版；
- 一份 QA 报告。

## 验收评分

| 维度 | 权重 | 通过标准 |
|---|---:|---|
| 内容 | 20% | 受众明确，一段一个结论，事实边界清楚 |
| 声音 | 15% | 普通话自然、术语正确、停顿支持理解 |
| 对齐 | 25% | 重点词与画面进入误差在门禁内，无抢跑/补出现 |
| 视觉 | 15% | 字号、安全区、箭头和重叠门禁通过 |
| 字幕 | 15% | 原文一致、语义完整、一行、时间正确 |
| 工程与复盘 | 10% | 版本、报告、失败证据和最小返工记录完整 |

## GitHub 仓库建议

公开仓库提交：

- `AGENTS.md`、`SKILL.md`、YAML 流程与 Harness；
- 脱敏后的模板、样例 manifest、检查脚本；
- 小型截图、流程图和 QA 示例；
- 发布文案样例与案例复盘。

不要提交：

- API Key、Token、私人 Voice ID；
- 个人声纹训练音频、数字人源视频；
- 未授权参考视频或完整转录；
- 大型 MP4/WAV、缓存、临时帧和失败渲染。

## 使用 Skill

Skill 位于 `course-video-pipeline/`。复制到 Codex skills 目录或在仓库内明确引用后，可使用：

```text
Use $course-video-pipeline to 把这段原始视频做成五章 PPT 动画课程。
```

Agent 会先建立项目 artifacts 和审核点，再进入配音与动画，不会直接从文稿跳成片。

## 发布仓库前检查

- 运行 Skill 快速校验；
- 运行仓库/项目 YAML 校验；
- 搜索绝对路径、Token、Voice ID 和邮箱；
- 检查 `.gitignore` 是否覆盖大型媒体；
- 选择并添加合适的开源许可证；
- 在 README 中标注第三方工具与素材许可边界。
