# Course Video Pipeline Agent Rules

## 项目目标

把原始视频、文稿或访谈转成可发布、可验证、可复用的分章 PPT 动画课程。默认产物包括：课程讲稿、语气规划、配音、逐词时间轴、动画源工程、逐章 MP4、字幕合并版、横竖封面和发布文案。

## 不可跳过的顺序

1. 盘点素材并锁定目标受众。
2. 建立规范化转录稿和术语表。
3. 拆分课程结构并形成每章唯一 `SCRIPT.md`。
4. 完成语气规划、停顿、重音和英文读音表。
5. 生成并人工确认最终配音。
6. 从最终配音生成 `WORD_ALIGNMENT`，再填写动画秒数。
7. 先做 `semantic-anchor-plan`，再做 `semantic-timing-manifest` 和定时分镜。
8. 先完成 15–20 秒高风险片段，再扩展到整章。
9. 通过语义、布局、运行时和人工听看门禁后才渲染整章。
10. 最后统一做字幕、五章合并、封面和发布包。

禁止从整段文稿直接跳到动画或成片。禁止在最终配音确定前锁定真实秒数。

## 唯一真相文件

| 问题类型 | 唯一真相 |
|---|---|
| 内容与措辞 | 当前版本 `SCRIPT.md` |
| 术语拼写/读音 | `terminology.yaml` |
| 语气、停顿、重音 | `tone-plan.yaml` |
| 实际时长 | 最终批准的音频及 `voice-manifest.yaml` |
| 语义出现时间 | `semantic-timing-manifest.yaml` |
| 动画对象与状态 | `timed-storyboard.yaml` / 动画源文件 |
| 字幕文字与时间 | 最终音频的逐词 ASR + `subtitle-manifest.yaml` |
| 发布标题与封面文案 | `publish-package.yaml` |

当两个文件冲突时，回到本表规定的唯一真相，不通过“拉长页面”“补几秒”或随机移动 CSS 解决。

## 角色分工

- **Human owner**：锁定受众、批准讲稿、声线、15–20 秒试片、逐章成片和发布包。
- **Luna Ultra**：素材理解、课程拆章、讲稿改写、语气规划、语义锚点、字幕断句、布局/语义审查。
- **Terra High**：按通过的 manifest 实现 HTML/GSAP/HyperFrames、接入音频、运行检查、渲染和最小修复。
- **SOL**：只处理同一语义冲突连续两轮仍未解决的裁决，输出冲突点、正确顺序、证据词和时间窗口；不得直接重写整章。
- **Toolchain**：转录、Fish Audio、逐词对齐、HyperFrames、FFmpeg、LatentSync、图像与媒体检测。

完整机器分工以 `workflow/role-routing.yaml` 为准。

## 质量门禁

- 一章只有一个当前讲稿版本；修改必须提升版本或写入修订记录。
- 同一句只用一条批准声线；英语术语先在术语表中锁定读法。
- 一个语义锚点对应一个主要视觉对象或一次状态变化。
- 视觉进入时间满足 `semanticStart-0.15s <= visualStart <= semanticStart+0.12s`。
- 与当前语义相关的视觉变化间隔不得超过 1.4 秒。
- 1920×1080 画布中，字幕安全区固定为 `y=900..1080`；关键内容必须停在 `y<870`。
- PPT 标题至少 54px，正文至少 24px，关键卡片/节点名至少 26px。
- 字幕一行，5–14 个可见字，文字与语音词序一致，目标提前 0.05 秒，最大词级误差 80ms。
- 字幕使用白色 52px 粗体字和真正半透明的深蓝承载层；底下 PPT 仍需可辨认。
- 任何数字人/对嘴视频只能保留一个人声音轨；外部生成视频若自带音频，必须在接入前检查并按设计静音或剥离。
- 横版 4:3、竖版 3:4 封面都必须做真实包围盒、换行、边界和平台裁切检查。

## 返工 Loop

1. 记录时间点、问题类别和证据截图。
2. 根据唯一真相表定位最小错误 artifact。
3. 只修改一个讲稿段、锚点、布局坐标、字幕组或媒体轨道。
4. 按场景 → 章节 → 总片逐级重渲染。
5. 运行机器检查、定点抽帧和人工听看。
6. 通过后冻结新版本；失败版本移入 `PastUselessDoc`。

不要通过重做整章掩盖局部错误，也不要删除失败证据。

## 文件与安全

- 所有文本、HTML、JSON、YAML 使用 UTF-8；写入后抽查中文和 HTML 标签，防止代码页转换造成乱码。
- 使用相对路径和环境变量，禁止把本机绝对路径写入可公开模板。
- 不提交 `.env`、API Token、私人 Voice ID、训练音频、数字人源视频或未经授权的第三方素材。
- 大型 MP4/WAV/MP3、缓存和临时帧不进入 Git；只提交可复现清单、脚本和小型示例。
- 修改已有项目时保留用户的无关改动，不覆盖已冻结版本。
