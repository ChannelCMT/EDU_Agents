# 第 4 章｜Route+Skill 与 Blackboard：让系统可控、可协作

版本：v02  
状态：已批准  
章节学习结果：能理解技能路由与共享状态的控制点

## 段落 1｜Route+Skill

Route+Skill 的关键不是让模型自由发挥，而是先让意图路由器选中一个 Skill，再执行这项可复用能力。这样更稳定、更容易缓存，也能用命中率评估效果；代价是 Skill 设计成本高，还要处理路由冲突。

## 段落 2｜Blackboard

Blackboard 则让多个 Agent 共同读写一份共享状态，状态变化推动下一步执行。它适合复杂协作，但状态模型、权限和追踪必须先设计好，否则出了问题很难定位。

## 动画意图

- 先出意图输入和 Router，再只点亮命中的 Skill 卡片。
- 用可缓存、可评估两个标签表现 Route+Skill 的收益，用冲突警示表现代价。
- Blackboard 出现共享状态面板，多个 Agent 读写同一面板；最后用追踪断点收束。
