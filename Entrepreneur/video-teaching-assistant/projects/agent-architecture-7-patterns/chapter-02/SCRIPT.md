# 第 2 章｜单 Agent 与 ReAct：从能跑到会探索

版本：v02  
状态：已批准  
章节学习结果：能区分单 Agent 与 ReAct 的边界和代价

## 段落 1｜单 Agent

单 Agent 就是一个大模型包揽输入、思考、调用工具和输出。它简单、便宜、延迟低，适合做概念验证和简单对话；一旦任务变复杂，模型容易认知过载，出现上下文污染。

## 段落 2｜ReAct

ReAct 把过程变成 Reason 加 Action 的循环：思考、行动、观察，再决定下一步。它比单 Agent 更适合多步探索，也更容易解释过程，但 Token 消耗大、容易跑偏，不适合直接承担大规模生产流程。

## 动画意图

- 先用一条直链展示单 Agent 的输入、思考、工具和输出。
- 讲到认知过载时，给上下文容器加警示标记，不让警示遮住字幕区。
- ReAct 出现时先显示 Reason、Action、Observe 三个节点，再闭合循环箭头。
