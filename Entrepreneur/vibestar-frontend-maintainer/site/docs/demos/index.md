## 共同录制规则

<ul class="check-list">
  <li>真实运行优先；一旦认证、网络或实时数据失败，立即切换冻结截图或预生成报告，不在课堂临时修密钥。</li>
  <li>不展示 Token、账户余额、浏览器私人侧栏、聊天通知、客户文件或本地私人目录。</li>
  <li>镜头只停在观众必须理解的判断点：输入、计划、关键工具调用、成功画面、人工闸门或失败兜底。</li>
  <li>每段都能单独剪成 30–90 秒短视频，但网站不嵌入或托管视频文件。</li>
</ul>
