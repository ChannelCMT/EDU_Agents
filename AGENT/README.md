# EDU_Agents 项目级 Agent 说明

## 项目定位

`EDU_Agents` 用来整理已经能够稳定交付结果的 AI 教育培训 Agent，并让它们以清晰的目录、可执行的说明和可复核的验收标准持续迭代。

项目服务两类受众：

- `Teenager`：青少年学习和实践方向。
- `Entrepreneur`：企业家和业务实践方向。

## 项目级职责

项目级 Agent 不直接执行某个具体业务流程，而是负责：

- 根据受众选择合适的 Agent；
- 维护成熟 Agent 注册表；
- 规定每层说明文档的职责；
- 监督复制迁移、隐私和验证边界；
- 让新贡献者可以从项目层逐层找到具体工作流。

Vibestar Agent 的页面导航和外部课件入口等具体维护边界，以其 `AGENT/manifest.yaml` 为准。

## 现有路由

- `Entrepreneur/video-teaching-assistant`：课程视频生产和视频助教流程。
- `Entrepreneur/vibestar-frontend-maintainer`：Vibestar 教学知识库和前端站点维护。
- `Teenager/`：当前没有已登记的成熟 Agent。

## 迭代原则

新增 Agent 的工作流程就是完善每一层的说明文档：项目层更新注册表，受众层更新清单和边界，Agent 层更新功能契约和变更记录，功能层更新实际工作流和交付物。
