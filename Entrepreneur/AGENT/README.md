# Entrepreneur 分类 Agent 说明

## 分类目标

为企业家和业务实践者提供能够直接支持课程交付、知识库维护和业务学习材料生产的成熟 Agent。

## 当前 Agent

| Agent | 能力边界 | 主要输出 |
|---|---|---|
| 视频助教 | 课程视频生产流程、语义对齐、字幕和发布质量门禁 | 课程项目、章节渲染流程、字幕/发布清单 |
| Vibestar 教学前端维护 | 教学知识库页面、页首导航（含外部课件入口）、VitePress 构建和 GitHub Pages 发布 | 可构建的学习站源码和交付记录 |

两个 Agent 的职责不同：视频助教负责视频内容生产链，Vibestar Agent 负责教学知识库和前端展示链。需要同时维护时，先完成内容和页面边界确认，再分别执行各自 Agent 的工作流。

## 成熟 Agent 纳入标准

- 已经有可复用的工作流或工程源码；
- 有明确输入、输出、失败处理和验收命令；
- 可以脱离本机绝对路径运行或通过配置补齐依赖；
- 不把秘密、私人素材和大体积生成物作为仓库前提；
- 主目录包含完整的 `AGENT/` 使用说明和迭代记录。
