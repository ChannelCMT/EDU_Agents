# 香港電腦通訊節｜灣星半年 AI Native 轉型暨 AI Builder Camp 路演 PPT 設計規格

## 1. 項目結論

以現有 `AI_Builder_Camp_15min_Roadshow_2026-08-29_30.pptx` 為內容基礎，另製一份面向香港電腦通訊節觀眾的 15 分鐘路演 PPT。原版保留，新版獨立交付。

新版不再以課程介紹開場，而以「未來，一個人會帶住一隊 AI Agent」建立注意力，再用灣星半年的 AI Native 轉型作真實主線，最後引導企業主報名 2026 年 8 月 29–30 日 AI Builder Camp。

全套簡報採用粵語講述、繁體中文投影片。主視覺會大量使用 Image 2／ImageGen 生成的統一科技形象，但所有生成圖只作概念視覺，不冒充真實客戶案例、真實活動照片或港科大（廣州）現場紀錄。

## 2. 溝通任務

15 分鐘結束後，觀眾應清楚記住三件事：

1. AI Agent 不只是一個新工具，而可能成為每位工作者可帶領的「數碼團隊」。
2. 灣星用半年時間，把網站建設、視覺設計、活動承辦與 AI 實訓四類業務逐步圍繞 AI Agent 重構。
3. 觀眾可以透過 AI Builder Camp，帶着一項真實業務入場，開始建立屬於自己的 Agent Team。

## 3. 受眾與場景

### 主要受眾

- 香港電腦通訊節現場的企業主、創業者、中小企決策者與在職專業人士。
- 已使用 ChatGPT 或其他生成式 AI，但仍停留在「問答、寫文案、逐個工具試用」階段的人。
- 想把 AI 變成可重複工作流程、可分工 Agent Team 與可驗收成果的人。

### 次要受眾

- 對 AI 實訓、青年發展或學校合作有資源的機構代表。
- 有興趣參與寒假中學生實訓、兩地青年合作或大學生項目的合作夥伴。

### 活動語境

- 香港電腦通訊節 2026 主題為「AI Connect: Let’s Link the Future」。
- 現場內容要先有未來感和可想像的個人角色，再落到灣星的真實轉型與可報名行動。
- 避免把簡報做成公司服務目錄、技術教程或純課程硬廣。

## 4. 轉化目標

### 第二轉化目標

## 5. 核心主張與用語

### 封面主題

**未來，你唔係一個人工作**  
**你會帶住一隊 AI Agent**

副標題：

**灣星半年 AI Native 轉型實戰｜由服務客戶到培養 AI Agent Boss**

### OPC 定義

OPC 指 One-Person Company。簡報使用的解釋是：

> OPC 唔係一個人做晒，而係一個人帶一支 AI 團隊。

### 灣星 AI Native 三原則

投影片必須使用以下已確認版本：

1. 「同 AI 講得清楚嘅工作，就唔再靠人傳話。」
2. 「人同人少啲傾執行，多啲傾 AI 搭建、商業判斷、創意想法同項目合作。」
3. 「唔係喺舊流程加 AI，而係圍繞 AI Agent 重構業務。」

### 灣星新定位

> 由代替客戶執行，轉向 AI 場景實訓、諮詢指導同項目陪跑，協助客戶建立自己嘅 Agent Team。

全場可重複的一句話：

> 灣星唔係用 AI 搶走客戶嘅工作，而係幫客戶建立一支真正屬於自己嘅 AI 團隊。

## 6. 事實與措辭邊界

1. 轉型週期一律寫「半年」，投影片不可殘留任何舊週期說法。
2. 四類業務一律寫：網站建設、視覺設計、活動承辦、AI 實訓。
3. 「AI Agent 數量會比人口多」只能作未來趨勢或產業預測，不可寫成已發生的全球統計。
4. 趨勢頁的安全寫法為：「未來，數碼員工可能比人類員工更多」，並附小字「產業預測，不是現況統計」。
5. 不虛構灣星的效率提升比例、收入、客戶數、廣告回報、節省工時或 Agent 數量。
6. 灣星與港科大（廣州）的表述固定為：

   > 灣星連接港科大（廣州）科研場景開展 AI 實訓。

7. 可補充參訪安排，但必須附上：

   > 參訪屬活動安排，不是校方課程或教授授課；具體安排以活動通知為準。

8. 不使用「聯合主辦」「校方課程」「教授授課」「官方認證」「港科大背書」等未獲公開資料支持的說法。
9. 生成圖不加港科大校徽、校名建築招牌或看似真實的學校活動照片。
10. 任何真實客戶、廣告帳戶、未公開項目資料與未授權人物照片均不出現。

## 8. 十三頁結構

### 第 1 頁｜未來，你會帶住一隊 AI Agent

- 頁面任務：用一句話改變觀眾對「個人工作」的想像。
- 主標題：未來，你唔係一個人工作／你會帶住一隊 AI Agent。
- 副標題：灣星半年 AI Native 轉型實戰｜由服務客戶到培養 AI Agent Boss。
- 角標：香港電腦通訊節 2026｜15 分鐘分享。
- 視覺：Image 2 生成主視覺；一位亞洲企業主或項目負責人站在畫面右側，身後連接一組有分工感的發光 Agent 節點；左側保留大字空間。
- 講述時間：45 秒。

### 第 2 頁｜未來，數碼員工可能比人類員工更多

- 頁面任務：建立趨勢張力，但不把預測當成現況。
- 主文案：未來，數碼員工可能比人類員工更多。
- 小字：產業預測，不是現況統計。
- 支撐內容：企業正由「員工使用 AI 工具」走向「人類編排多個專門 Agent」。
- 視覺：Image 2 生成一位人類協調者與向遠方擴展的數碼 Agent 網絡；畫面不出現精確人數、百分比或假圖表。
- 備注來源：NVIDIA、TCS、Goldman Sachs 對多 Agent 團隊與數碼勞動力的公開預測。
- 講述時間：55 秒。

### 第 3 頁｜OPC 唔係一個人做晒，而係一個人帶一支 AI 團隊

- 頁面任務：把抽象趨勢轉成觀眾可代入的身份。
- 主文案：One-Person Company = 一個人做判斷，一隊 Agent 做分工。
- 分工示例只列五個詞：研究、內容、設計／開發、檢查、項目管理。
- 視覺：Image 2 生成企業主在科技指揮台前，周圍是五個不同職能的 Agent 光體或介面；不加入可讀假 UI。
- 講述時間：60 秒。

### 第 4 頁｜灣星用半年，開始轉型成 AI Native 公司

- 頁面任務：由未來趨勢落到灣星真實案例。
- 主體：三條 AI Native 原則，使用第 5 節的已確認原文。
- 次要內容：灣星由大灣區跨境品牌與機構傳播夥伴，逐步把 Agent 融入項目交付。
- 視覺：灣星官網真實截圖與 Image 2 生成的抽象企業工作流背景疊合；官網截圖負責品牌可信度，生成圖負責科技氣氛。
- 講述時間：70 秒。

### 第 5 頁｜四類業務，開始深度融合 AI Agent

- 頁面任務：讓觀眾一眼看懂灣星的四個真實應用入口。
- 四類業務：網站建設、視覺設計、活動承辦、AI 實訓。
- 每類只保留一個成果詞：網站上線、品牌資產、活動交付、Agent 能力。
- 視覺：以一條由左至右的發光主線連接四個真實業務素材；優先使用灣星官網公開案例圖，不做密集卡片牆。

### 第 6 頁｜灣星點樣用一支 AI 團隊服務客戶

- 頁面任務：展示「人帶 Agent Team」而不是「AI 自動做晒」。

- Agent 分工：研究 Agent、內容 Agent、設計／開發 Agent、檢查 Agent、項目 Agent。
- 人類責任：商業判斷、創意方向、客戶關係、最終驗收。
- 視覺：Image 2 生成企業級 Agent Team 網絡主視覺；文字標籤由 PowerPoint 原生文字添加，避免生成圖文字錯誤。
- 講述時間：70 秒。

### 第 7 頁｜一個客戶項目，唔再由一個人由頭做到尾

- 頁面任務：用完整流程證明 Agent Team 如何協作。
- 流程：客戶需要 → 研究 → 方案 → 網站／視覺／活動物料 → 檢查 → 交付 → 知識沉澱。
- 轉折句：人不是消失，而是從逐件執行轉向定方向、作判斷與驗收。
- 視覺：Image 2 生成「人類負責人沿一條數碼生產線編排多個 Agent」的橫向概念畫面；流程節點和箭頭由原生 PPT 圖形添加。

### 第 8 頁｜灣星唔想永遠代你執行，而係幫你建立自己嘅 Agent Team

- 頁面任務：完成商業模式轉向。

- 主結論：由代替客戶執行，轉向協助客戶建立自己的 Agent 能力。
- 視覺：由「灣星 Agent Team」交接給「客戶 Agent Team」的雙方協作畫面；採用簡潔的接力構圖，避免複雜示意圖。

### 第 9 頁｜第一步唔係買工具，而係揀啱一個真實場景

## 9. Image 2／ImageGen 視覺資產計劃

### 視覺策略

採用「概念圖負責吸引、真實素材負責可信」的雙軌方法：

- Image 2／ImageGen：負責未來 Agent、OPC、Agent Team、客戶流程與科技實訓等難以用現成照片表達的抽象概念。
- 灣星官網、AI Builder Camp 活動頁與課程頁：負責公司身份、真實業務、日期、場地安排、課程成果與報名資訊。
- PowerPoint 原生文字和簡單圖形：負責所有可讀標籤、流程節點、註解與數據，避免生成圖內文字錯誤。

### 統一影像語言

- 類型：高質感企業科技攝影與寫實概念視覺，不使用卡通機械人或廉價霓虹賽博龐克。
- 色調：近黑海軍藍、電光藍、冷白，少量金色作關鍵節點。
- 人物：以亞洲企業主、項目負責人和多元成年學員為主；自然、自信、非科幻戰士。
- Agent 表達：以發光節點、半透明光體、連線、任務軌跡或抽象數碼分身呈現，不使用有臉機械人。
- 構圖：16:9 寬幅；按文字區預留負空間；重要人物不置於裁切邊緣。
- 禁止：生成文字、假品牌、假校徽、假客戶 Logo、浮水印、可讀假 UI、精確虛構數字、過度密集 HUD。

### 六張主要生成圖

1. `hero-agent-team`：封面；一位人類帶領一隊 Agent，人物靠右、左側留白。
2. `digital-workforce-growth`：Agent 數量趨勢；一位人類協調者與向遠方擴展的 Agent 網絡。
3. `opc-command-center`：OPC；一位企業主帶領五類職能 Agent。
4. `starbay-agent-team`：灣星服務客戶；人類項目負責人連接研究、內容、設計／開發、檢查與項目 Agent。
5. `agent-project-pipeline`：客戶項目；人類沿數碼生產線編排多 Agent，由需要走到知識沉澱。
6. `ai-builder-camp-workshop`：企業主實訓；多位成人在未來感但可信的培訓空間用筆電協作。

視需要可再生成第 7 張 `handoff-client-agent-team` 作第 8 頁的能力交接畫面。每張主要生成圖原則上只使用一次，背景紋理除外。

### Prompt 結構

每次生成使用 `stylized-concept` 或 `ads-marketing` 類型，提示詞至少包含：

- 用途：16:9 PowerPoint 科技主視覺；
- 場景與主體；
- 人物或 Agent 的畫面位置；
- 需要的文字安全區；
- 統一色調、光線和企業級質感；
- 「no text, no logo, no watermark, no readable UI」；
- 「concept visual, not documentary photography」或等價邊界提示。

生成後必須逐張檢查人物手部、面部、屏幕內容、構圖、裁切與色彩一致性。被 PPT 使用的最終圖須保存到項目工作區，不只留在 ImageGen 默認位置。

## 10. 投影片視覺系統

- 畫布：16:9，1280 × 720 或等比例 PowerPoint 寬屏。
- 底色：近黑海軍藍 `#07111F`。
- 主文字：冷白 `#F4F7FB`。
- 強調色：電光藍 `#1F6FFF`。
- 次強調：青藍 `#42D8FF`。
