# 7 种 Agent 架构选型视频：设计规格

## 目标

把抖音原视频《手把手带你解析从零搭建 Agent 系统主流 7 种架构选型指南》改造成预演未来课程风格的 5 章教学视频，用来验证 `courseVedio` Loop 能否从原始视频完整交付到可发布素材。

## 已确认的输入

- 原视频 URL：`https://v.douyin.com/_OlflTEBJuQ/`
- 页面标题：手把手带你解析从零搭建 Agent 系统主流 7 种架构选型指南
- 页面时长：约 2:56.8
- 页面给出的 7 个架构：单 Agent、ReAct、Plan and Execute、多 Agent、Route+Skill、Blackboard、Graph Workflow
- 原视频给出的选型主线：场景复杂程度与控制力需求；演进路径为单 Agent → 多 Agent 协作 → 基于图的 Workflow

## 受众与教学结果

面向需要把 Agent 落到真实业务和项目中的企业家与技术学习者。观看完成后，学习者应能够：

1. 说出 7 种架构的核心工作方式和主要代价。
2. 用“场景复杂度 × 控制力需求”做一次初步选型。
3. 为自己的任务写出一份包含架构、理由、风险和验证点的最小选型记录。

## 章节结构

采用 5 章而不是 7 章逐一讲解，以保留原视频的完整信息，同时让每章承担一个明确的教学任务。

| 章节 | 教学任务 | 覆盖架构 | 视觉主线 |
|---|---|---|---|
| 01 | 建立选型坐标系 | 复杂度、控制力、演进线 | 两轴坐标与决策门 |
| 02 | 理解单步到可解释循环 | 单 Agent、ReAct | 任务→思考→工具→结果 |
| 03 | 理解计划和协作的代价 | Plan and Execute、多 Agent | 计划树、角色协作、上下文边界 |
| 04 | 理解企业级路由和共享状态 | Route+Skill、Blackboard | 路由器、技能库、黑板状态 |
| 05 | 用图编排长流程并完成选择 | Graph Workflow、完整演进线 | 节点图、回滚、选型清单 |

## 视觉与声音

- 画布：16:9，1920×1080；后续生成 3:4 封面，不重排主视频。
- 风格：深蓝底、浅蓝高亮、白色正文、浅灰辅助，少量黄色只用于结论或当前节点。
- 版式：标题至少 54px，正文至少 24px，关键节点至少 26px；底部字幕安全带预留 y=900–1080，主内容不得侵入。
- 讲稿：保留原视频事实，但改成自然、完整、可朗读的中文；英文术语固定拼写并单独做发音校验。
- 配音：使用已审核的 Channel 科技解说风格；最终音频是时间真相，不让动画反向拉伸音频。
- 字幕：逐字与配音一致；每条 5–14 个可见汉字，尽量完整成句；单行、半透明深蓝底框，起始时间比语音提前 50ms。

## 交付物

1. 原视频登记、转写稿、术语表、内容改写稿。
2. 5 章语气规划、最终音频、词级时间对齐和语义锚点。
3. 5 章分镜、动画工程、章节 MP4 与合并 MP4。
4. 对齐后的字幕文件与烧录字幕视频。
5. 横版与竖版封面、标题、简介、话题词、发布清单。
6. 最终 QA 报告和可复用的 artifact manifest。

## 质量门禁

- 视觉锚点需满足 `semanticStart - 0.15 <= visualStart <= semanticStart + 0.12`。
- 相邻语义锚点之间不得出现超过 1.4 秒的无意义静止。
- 先通过 15–20 秒对齐试片，再渲染整章。
- 最终只能有一条连续旁白流；不得发生音轨重叠或重复混音。
- 章节和合并视频均需检查：标题/正文最小字号、字幕安全区、文本框重叠、箭头方向、英文术语、字幕与语音误差 ≤80ms。

## 范围边界

本轮默认不加入数字人，以验证 Loop 的核心交付链路；数字人只作为后续增强层，不阻塞本轮交付。
